# 머신러닝을 활용하여 AI 운동 코치 만들기 (마이크로비트 수업 슬라이드)

2026학년도 결빛 네트워크 연계 구산 「CODE_Boost」 주말 코딩 캠프 원고예요. 강사는 부내초 교사 유경윤이에요.

손목에 찬 micro:bit가 머신러닝으로 점핑잭·스쿼트·가만히를 알아보고, 운동한 시간을 재 주는 'AI 운동 코치'를 만들어요. micro:bit CreateAI로 데이터를 모아 학습시키고, MakeCode 블록으로 코딩해요.

- **PDF 받기:** 화면 아래쪽에 마우스를 올리면 나오는 [PDF 다운로드] 버튼
- **슬라이드 번호로 바로 가기:** 주소 끝에 `#16`처럼 번호를 붙여요

## 구성

1. 도입 (1~8장): 지난 시간 흔들림 카운터 떠올리기, 규칙 vs 머신러닝, 몸으로 하는 동작 맞히기 게임, 작품 소개
2. CreateAI (9~24장): 준비물, 연결하기, 동작 정하기와 데이터 모으기, 모델 훈련·테스트, 모델 고치기, 미션 체크
3. MakeCode 블록 코딩 (25~34장): 기계 학습 블록, 1단계 동작 알아보기, 2단계 운동 시간 재기, 3단계 30초 축하, 완성 코드
4. 마무리 (35~40장): 문제 해결, 1분 운동 대회, AI와 공정성, 스스로 해보기, SDGs 연결, 정리

## 준비물

micro:bit V2, 배터리 팩, 손목 밴드, USB 데이터 케이블, Chrome 또는 Edge가 있는 컴퓨터가 필요해요. 컴퓨터에 블루투스가 없으면 micro:bit V2가 1대 더 필요해요.
